# 05. Unified Communications

Source: `5. Unified Communications.pdf` (6 pages including a competitor comparison table).

## In one sentence

A cloud phone system and team-collaboration platform in one: calls, video, chat, file sharing and a
hosted PBX that work the same on desktop, browser, mobile app and desk phone.

## Background

The underlying platform (named MobileUC in the brochure) is a carrier-grade, white-label product that
service providers deliver under their own brand. Hypernet delivers it as Hypernet Unified
Communications, so the platform name is not used on the site.

## What it does for the customer

- **Same experience everywhere**: identical features on desktop, web, iOS/Android apps and IP desk
  phones.
- **Collaboration**: group chat, file sharing, screen sharing and multi-party video meetings.
- **Easy onboarding**: each new user gets a personalised email and signs in with one click
  ("magic link").

## Feature set

| Area | Included |
|---|---|
| Cloud PBX | Auto-receptionist, multi-level IVR, call reports, audit trails. |
| Mobility | Dedicated iOS and Android apps, HD voice and video over Wi-Fi, 3G or LTE. |
| Productivity | Visual voicemail, fax-to-email, find-me/follow-me, Slack-style team chat. |
| Business intelligence | Detailed usage reports; real-time NOC dashboard with monitoring and alerts. |

## Reliability and security

- **Geo-redundant, active-active cluster**: survives a whole data centre failing without dropping
  service.
- **Scale**: from one user to 500,000+ on the same platform.
- **Security by default**: firewalling, geo-blocking (blacklisting countries), fraud controls with
  daily spend limits, rate-limited APIs.

## Integration

- APIs for Office 365, CRM platforms and AD/LDAP directories.
- Bulk CSV upload for users and handset provisioning, which makes migrations fast.

## Comparison claims

A summary table compares the platform to an "industry standard":

| | This platform | Typical alternative |
|---|---|---|
| User capacity | 500,000+ | ~100 to 10,000 |
| White-labelling | Fully brandable | Limited |
| Redundancy | Geo-redundant cluster | Single site or paid add-on |
| Multi-tenancy | High density, native | Tenant limits |
| Architecture | Active-active | Active-passive or single |

A detailed table also compares it with Mitel, 3CX, Bicom, Netsapiens and Yeastar on trial,
licensing, multi-tenancy, HA, geo-redundancy, Office 365 integration, call-centre management,
omni-channel, dialler, onboarding and annual software costs. The table is partly inconsistent in the
source (misaligned cells), so the site only uses the simple "typical hosted PBX" comparison and does
not name competitors.

## The service wrapper

The brochure's line is "Your phone system is only as good as the people supporting it." The
provider has worked in voice since the on-site PBX era and helps design, migrate and support the
environment, with fast fixes when someone cannot make or take a call.

## Positioning versus Hypernet VoIP

VoIP = business phone lines and numbers. Unified Communications = VoIP plus video, chat,
collaboration, mobile apps and a full cloud PBX. The UC page links back to VoIP for customers who
only need lines.
