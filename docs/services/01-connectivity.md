# 01. Connectivity

Source: `1. Connectivity.pdf` (4 pages: cover, why us, the solution, the process).

## In one sentence

Business-grade internet designed around how the customer works: a primary fibre line, a
wireless link that takes over when the fibre is cut, and a managed SD-WAN layer that steers important
traffic across whichever path is healthiest.

## The problem it answers

Businesses that run on cloud software, VoIP and card machines depend on the internet line for
almost everything. A few seconds of latency drops calls, and an afternoon of downtime stops trading.
Multi-branch businesses are hit hardest, because every site depends on the same data.

## How the brochure positions the provider

The brochure presents the provider as a technology partner that assesses the workflow first,
designs in redundancy and then manages the network for the customer. It gives three reasons:

- **Carrier relationships.** Traffic is routed over top-tier transit networks, chosen for the best
  route and lowest latency for each specific site.
- **Watching the network all the time.** Engineers monitor performance around the clock and correct
  routing problems before users notice.
- **No generic packages.** Each design is sized to the site's traffic volume, the hardware already
  there and any compliance needs.

## The three packages

### A. Dedicated business fibre

- **Symmetrical speeds**: upload is as fast as download, which matters for cloud backups, video
  calls, large file uploads and hosted apps.
- **Backed by an SLA**: latency and uptime commitments in writing (the brochure says
  "industry-leading" but gives no number, so the site does not invent one).
- **Scalable bandwidth**: capacity can be raised as the business grows without re-cabling or new
  hardware.

### B. Microwave and fixed-wireless links

- **Fast to deploy**: no trenching, so a site can be live far sooner than waiting for a fibre build.
- **Branch bridging**: joins remote offices, warehouses and satellite sites onto the main network.
- **Failover**: a wireless backup that switches in automatically when the fibre is cut
  (cable theft and roadworks being a very South African problem).

### C. Managed SD-WAN and network design

- **Smart routing**: business-critical traffic (VoIP, cloud apps) is sent down whichever path is
  fastest at that moment.
- **One console for everything**: every branch, remote worker and cloud environment is managed from
  a single view.
- **Security at the edge**: zero-trust access rules and automated threat mapping at each point where
  data changes networks.

## The process (three steps)

1. **Understand and diagnose**: map the current network, find the bottlenecks, understand the goals.
2. **Design and build**: engineer a layered design, typically primary fibre with automatic wireless
   backup.
3. **Implement and adopt**: roll it out in a sequence that keeps downtime minimal, then test
   throughput at every endpoint.

## Who it suits

Any business where the connection is critical: multi-branch retail, offices on cloud software,
logistics sites, anyone running VoIP. The brochure's language is enterprise-flavoured; Hypernet
reframes it for SMEs and growing businesses.
