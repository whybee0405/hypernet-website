# Service reference notes

Working notes distilled from the seven partner brochures in `extra reference service packages/`.
One file per brochure. Each file summarises what the service is, who it is for, what is inside
each package, the claims the brochure makes, and how we have positioned it on the Hypernet site.

The brochures are BVS Telecom collateral (Fourways, Johannesburg). Hypernet sells these services
under its own name, so nothing on the public site mentions BVS, its address, its phone number or its
"Tried. Tested. Trusted." line. Third-party technology vendors (Cloudflare, Sophos, Sendmarc,
Flowgear) are named where knowing them helps a buyer decide, which is how the brochures present them.

## Four pillars

The megamenu groups the nine offers into four jobs a business owner recognises:

1. **Connect**: business internet (fibre, wireless, failover), CloudPath SD-WAN.
2. **Communicate**: VoIP, Unified Communications, Omni-channel Contact Centre.
3. **Protect**: Secure Business, Dragon Guard.
4. **Automate**: Integration Suite.

## Claims policy

No brochure contains a price, so every package on the site is quoted per customer. Vendor figures quoted in the brochures (e.g. 250+ connectors, 100+
translation languages, 52 international PoPs, 500,000-user platform ceiling) are vendor platform
specifications, and the site presents them as such. The site does not quote SLA or uptime numbers;
where a brochure says "industry-leading SLA", the site says the SLA is agreed in writing per
connection.
